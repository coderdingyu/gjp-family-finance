# 界面截图

供《用户手册》第三部分「用户操作手册」使用。
截图环境：Chrome 无头模式，视口 1440px 宽，2 倍像素密度，演示账号 zhangwei / 张家。

| 文件                       | 页面           | 说明                                             |
| -------------------------- | -------------- | ------------------------------------------------ |
| `login.png`                | 登录页         | 登录页签                                         |
| `login_register.png`       | 登录页         | 注册新家庭页签                                   |
| `home.png`                 | 家庭看板       | 指标卡、收支趋势、支出结构、成员对比、商家排行等 |
| `record.png`               | 收支流水       | 多条件查询 + 流水列表 + 汇总条                   |
| `record_dialog.png`        | 收支流水       | 录入弹窗，分类级联展开（当前为支出分类）         |
| `record_dialog_income.png` | 收支流水       | 切到「收入」后分类候选随之切换                   |
| `stat.png`                 | 统计报表       | 趋势、分类占比、分类明细、成员对比               |
| `analysis.png`             | 智能分析       | 分析结论列表（结论 + 数据依据 + 处理建议）       |
| `asset.png`                | 资产负债       | 净资产总览、资产列表、资产构成、贷款还款进度     |
| `member.png`               | 成员管理       | 成员列表与月度预算                               |
| `category.png`             | 分类管理       | 两级分类树，预置与自定义区分                     |

重新生成截图的脚本在会话临时目录，若需重做可直接手工截图，
或用 Chrome 无头模式 + DevTools Protocol 逐页截取。

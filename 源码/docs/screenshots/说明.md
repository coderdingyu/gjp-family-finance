# 界面截图

供《用户手册》第三部分「用户操作手册」使用。
截图环境：Chrome 无头模式，视口 1440px 宽，2 倍像素密度，读取的是打包后的单 jar（http://localhost:8080）。

## 户主视角（zhangwei）

| 文件               | 页面     | 说明                                                         |
| ------------------ | -------- | ------------------------------------------------------------ |
| `login.png`        | 登录页   | 登录页签                                                     |
| `login_register.png` | 登录页 | 注册新家庭页签（注册人成为户主）                             |
| `home.png`         | 家庭看板 | 指标卡、收支趋势、支出结构、成员对比、商家排行、片区、预算   |
| `record.png`       | 收支流水 | 多条件查询 + 流水列表；分类列显示三级完整路径                |
| `record_dialog.png` | 收支流水 | 录入弹窗，分类级联展开                                       |
| `stat.png`         | 统计报表 | 趋势、分类占比、分类明细（可逐层钻取到三级）、成员对比       |
| `analysis.png`     | 智能分析 | 分析结论列表（结论 + 数据依据 + 处理建议）                   |
| `dedup.png`        | 账单查重 | 5 组疑似重复，标注「完全一致 / 高度相似」与建议保留项        |
| `asset.png`        | 资产负债 | 净资产总览、资产列表、资产构成、贷款还款进度（仅户主可见）   |
| `member.png`       | 成员管理 | 成员列表与月度预算                                           |
| `accounts.png`     | 成员账号 | 户主为成员开通登录账号、重置密码、启用禁用（仅户主可见）     |
| `category.png`     | 分类管理 | 三级分类树，一级/二级/三级与预置/自定义区分                  |
| `log.png`          | 操作日志 | 按模块/动作/结果/时间筛选；户主可见全家操作                  |
| `ball_panel.png`   | 悬浮球   | 展开后的两个入口：手动记账 / 文件上传                        |
| `ball_form.png`    | 悬浮球   | 快速记账表单，已选到三级分类「文化娱乐/影音娱乐/游戏充值」   |
